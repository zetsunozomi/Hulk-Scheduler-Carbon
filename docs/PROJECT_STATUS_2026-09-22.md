## 目标一：动态是否打赢 fixed

下表只报告最终第64轮 checkpoint 的 development validation。C 是两个功率端点归一化平均碳成本中的较大者，越低越好；不是实测碳排。Best-Fixed 从同批 validation 上满足5%经验 miss 目标的固定规模中选取；Fixed-Mix 也在该 validation 上拟合。

| D(h) | RL C | RL misses | Best-Fixed / C | RL 相对 Best-Fixed | Fixed-Mix C | RL 相对 Fixed-Mix |
|---:|---:|---:|---|---:|---:|---:|
| 15.1077 | 1.166781 | 14/24 | 无可行固定规模 | — | 不可行 | — |
| 59.7915 | 1.211431 | 0/24 | Fixed-64 / 1.166781 | +3.827% | 1.122030 | +7.968% |
| 104.4754 | 1.092272 | 0/24 | Fixed-16 / 1.092195 | +0.007% | 1.090776 | +0.137% |
| 193.8431 | 1.131543 | 0/24 | Fixed-16 / 1.092195 | +3.603% | 1.088788 | +3.927% |

最紧预算在现有动作定义和这批到达上不可达到5% miss，保留并标记该点。其余三档最终 checkpoint 尚无 fixed 优势。

不能忽略中间 checkpoint 的微小正结果：第32轮、104.4754h档 C=1.090670745，低于 Fixed-16 约0.1396%、Fixed-Mix 约0.0096%；两个功率端点对 Fixed-Mix 的比值为0.999284912和0.999903636。第48轮对 Fixed-16 仍略低，但已高于 Fixed-Mix；第64轮基本持平 Fixed-16。这些是单 panel/seed、24个到达的描述性验证结果，没有置信区间，不能建立稳定收益。

原 Plan-once/MPC 在59.79h档也有描述性优势：C≈1.106055、miss=1/24，比 Fixed-Mix 的最坏端点目标低约1.42%。两规划方法在该档执行结果相同，且rho=.25相对 Fixed-Mix 略高，因此尚不支持反馈增量、RL优势或全功率区间优势。

## 目标二：是否仍收敛为单一选择

跨所有预算都选64的问题，在本次候选的已评价状态上已打破，并保持到第64轮。更强的“有用的状态反馈已学会”仍未成立。

| D(h) | 第64轮平均首次动作概率 P(4/16/64/128) | 任务内实际换规模 | 首次 argmax 在24个到达上的情况 |
|---:|---|---:|---|
| 15.1077 | ≈0 / ≈0 / 99.98% / 0.02% | 0/24 | 全部64 |
| 59.7915 | 1.12% / 3.29% / 89.93% / 5.66% | 1/24 | 全部64 |
| 104.4754 | 0.37% / 99.61% / 0.019% / 0.001% | 10/24 | 全部16 |
| 193.8431 | 46.79% / 48.08% / 4.53% / 0.59% | 19/24 | 全部16 |

104.48h档的24个任务均先选16，后续为14×[16,16]、8×[16,4]、1×[16,64]、1×[16,128]。193.84h档保持多动作采样与切换，但首次 P(4) 在不同到达间仅变化于45.05%–47.19%，P(16)为46.37%–48.54%，更接近稳定随机混合；不能把采样出的不同动作直接解释为队列反馈。

两个宽预算的任务内换规模数在四个 checkpoint 上分别是12/11/12/10和18/16/19/19（每次分母24）。因此可以报告持续的非单动作执行；不能由此推断切换有收益或反馈必要。跨预算 TV 增大也不能单独证明同一预算内的状态利用，尤其这次采用四个独立分支。
