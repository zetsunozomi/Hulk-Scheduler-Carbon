\subsection{Training-Workload Profiles}
\label{sec:impl:workload}

The simulator represents completion of 100,000 iterations for three GPT-2
configurations.  For each model, define the reference work in 4-node-equivalent
node-hours as

\begin{equation}
    W_{\mathrm{total}} = 4T_4,
\end{equation}

where $T_4$ is the wall-clock duration of that workload's 4-node profile.  For
node count $n$, Table~\ref{tab:scaling_efficiency} gives the node-hour cost
$W_n=nT_n$ supplied to the simulator.  These values are workload-profile
inputs to the trace-driven evaluation; the reported scheduling results are
conditional on them.
The current artifact does not identify the machine on which every profile was
measured or report the software stack, sequence length, micro-batch and
accumulation settings, repetitions, or measurement uncertainty.  We therefore
do not treat this table as evidence of cross-machine scaling generality.
